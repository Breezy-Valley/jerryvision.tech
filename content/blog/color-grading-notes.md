# DaVinci Resolve 调色笔记：从一级校色到风格化

用 DaVinci 快两年了，把一些常用的节点树和思路整理一下。

## 一级校色

拿到素材第一件事永远是校正。我的习惯节点顺序：

1. **降噪** — 如果素材噪点明显，先做一轮空域降噪
2. **白平衡** — 用色轮或 curves 校准
3. **曝光** — 把中灰拉到合适位置
4. **对比度** — 控制反差，不急着拉太大

## 二级调色

校完基础色调之后才开始做风格：

- **肤色保护** — 用 qualifier 选出肤色范围单独处理
- **色调分离** — 高光偏暖、阴影偏冷是我常用的搭配
- **暗角** — 轻微的暗角引导视线，但要控制好量

## 节点树管理

建议养成命名节点的习惯，不要留一堆 `Corrector 1`、`Corrector 2`。

我的典型节点结构：

```
[NR] → [WB] → [EXP] → [CTR] → [SHADOW/HIGHLIGHT] → [SKIN] → [LOOK] → [VIGNETTE]
```

## 输出注意

给不同平台的输出 gamma 不一样。B 站和抖音用 Rec.709-A，给电视台用 Rec.709 Gamma 2.4。
